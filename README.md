Установка программы Фермерские рынки<br>
Скачать файл Farmer_markets_install. Запустить farmer_markets.exe.<br>

 Описание.<br>
 Программа принимает файл с данными формата csv. Преобразует его в файлы локальной базы данных SQLite.<br>
# В разделе "Просмотр всех фермерских рынков" выводиться информация о фермерских рынках в формате:<br>

fmid,      Название рынка,               адрес,           город,        локация,    штат,        zip код,     долгота (lon),    широта (lat)   рейтинг<br>
1000194,   Riverside Farmers' Market,    10 Pine Ave.,    Riverside,    Cook,       Illinois,    60546,      -87.8201027,       41.8277856,     5<br>

# В разделе "Поиск фермерских рынков" доступны подразделы:<br>
- по названию города и штата - в два доступных поля нужно ввести соответствующие названия на англ.языке и нажать кнопку "Поиск";<br>
- по zip коду - в одно поле нужно ввести пятизначный цифровой zip код и нажать кнопку "Поиск.<br>

 Если поиск выдает несколько строк, то можно выделить мышкой нужную строку и задать поиск по расстоянию ("Найти все рынки в радиусе, миль).
Также можно выделить любую найденную строку в этом разделе и задать поиск по расстоянию. Подтвердить кнопкой "Поиск".<br>

 Есть возможность оставить отзывы и поставить оценку(рейтинг) рынку. Если одна строка выделена, отзыв будет относиться к этому рынку,
кнопка "Оставить отзыв" становиться активной. Рейтинг рынка рассчитывается по среднему значению  в зависимости от всех оставленных на него отзывов<br>

 Кнопка "Открыть настройки" позволяет настраивать размеры шрифта основного окна, а также входить в панель администратора, где можно увидеть
все отзывы в табличном виде, а также рейтинги и кто их оставлял. <br>

Для удаления отзыва нужно выделить строку, нажать кнопку "Удалить" и подтвердить введением пароля что Вы являетесь администратором.<br>
