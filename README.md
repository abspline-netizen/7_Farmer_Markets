Установка программы Фермерские рынки
Скачать файл Farmer_markets_install. Запустить farmer_markets.exe.

 Описание.
 Программа принимает файл с данными формата csv. Преобразует его в файлы локальной базы данных SQLite.
# В разделе "Просмотр всех фермерских рынков" выводиться информация о фермерских рынках в формате:

fmid,      Название рынка,               адрес,           город,        локация,    штат,        zip код,     долгота (lon),    широта (lat)   рейтинг
1000194,   Riverside Farmers' Market,    10 Pine Ave.,    Riverside,    Cook,       Illinois,    60546,      -87.8201027,       41.8277856,     5

# В разделе "Поиск фермерских рынков" доступны подразделы:
- по названию города и штата - в два доступных поля нужно ввести соответствующие названия на англ.языке и нажать кнопку "Поиск";
- по zip коду - в одно поле нужно ввести пятизначный цифровой zip код.

 Если поиск выдает несколько строк, то можно выделить мышкой нужную строку и задать поиск по расстоянию ("Найти все рынки в радиусе, миль).
Также можно выделить любую найденную строку в этом разделе и задать поиск по расстоянию.

 Есть возможность оставить отзывы и поставить оценку(рейтинг) рынку. Если одна строка выделена, отзыв будет относиться к этому рынку,
кнопка "Оставить отзыв" становиться активной. Рейтинг рынка рассчитывается по среднему значению  в зависимости от всех оставленных на него отзывов

 Кнопка "Открыть настройки" позволяет настраивать размеры шрифта основного окна, а также входить в панель администратора, где можно увидеть
все отзывы в табличном виде, а также рейтинги и кто их оставлял. 

  Для удаления отзыва нужно выделить строку, нажать кнопку "Удалить" и подтвердить введением пароля что Вы являетесь администратором.
  Пароль администратора 12345.
